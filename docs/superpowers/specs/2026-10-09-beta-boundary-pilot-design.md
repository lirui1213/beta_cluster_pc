# Beta 语句边界预测预实验

## 目标与数据

检验 beta 下降是否能提前预测发声起始和结束，分别报告两项结果。默认使用当前四频带 Notebook 指定的 HS0015/B03，原始连续 ECoG 位于 `I:/ECoG_data/HS0015/blocks/B03/standardized/ECoG/ecog_TEST_clean_car-raw.fif`，标签使用同目录体系中的 `events/onset.npy` 和 `events/offset.npy`。已确认 48 对事件、400 Hz、128 个 ECoG 通道、291.0025 秒记录，FIF 标记 2 个坏道。语句时长中位数 2.988 秒，范围 2.385–10.642 秒。

事件文件暂作为发声边界标注；文件本身不证明其标注方式，报告应说明未重新人工核验音频。原始 FIF 已经包含既有清理与 CAR；预实验只能保证新增处理因果，不能据此宣称原始清理全程满足在线条件。

## 方案比较与选择

1. 推荐：因果 beta 功率/斜率加正则化逻辑回归，与下降阈值和时间基线比较。适合现有样本量，可解释、可重复。
2. 只做下降阈值：更直接，但可能遗漏多通道联合信息；保留作为对照。
3. 多频带或复杂时序网络：本轮不采用，避免小样本下增加模型搜索和解释难度。

## 信号与标签

在连续原始记录上排除 FIF 坏道，以有状态单向 SOS 带通提取 13–30 Hz 信号，平方后用因果指数平均估计功率，不使用零相位滤波、Hilbert 全段包络或对称平滑。在约 50 ms 网格提取 log 功率及过去 100/250/500 ms 的功率变化。滤波启动预热段排除。所有特征只依赖当前及过去样本，处理延迟计入报警时间，不向前移动结果。

主任务定义为：在当前时刻之后 100–500 ms 内是否发生目标边界。起始、结束分别训练；连续评估保留句中、句间、暂停等负样本，不用真实语音状态限制模型报警。音频只用于标签解释与对照，不作为神经预测输入。

## 拆分与对照

按事件顺序约 60%/20%/20% 分为训练、验证、最终测试，保持连续时间顺序，在分割边缘排除至少 1 秒以避免跨段标签窗与历史特征重叠。所有标准化、通道筛选、模型拟合在训练段完成；阈值仅在验证段确定。最终测试仅用于一次固定方案评估，不依据测试结果改选通道或参数。不使用既有全数据聚类结果选通道，也不做语句时长百分比归一化。

下降阈值对照使用训练段选出的通道与因果下降特征。时间基线利用训练段的句长或间隔分布及最近已知边界估计风险；其真实历史边界依赖明确标注为 oracle 辅助对照，不能称为完全自主在线系统。神经模型本身不接收真实边界、trial 编号或录制时间。若神经模型只胜过机会而没有超过时间基线，结论为尚未证明额外预测价值。

## 评估与交付

验证段选取满足不高于每分钟 2 次误报的报警阈值，在可行阈值中优先选择事件召回率高者；若没有有效报警则如实报告。报警以阈值上穿触发，并设置 1 秒不应期。一次报警只匹配一个未来 100–500 ms 的目标事件，一次事件最多计一次命中，重复与窗外报警计为误报。

报告每个任务的测试事件数、命中率、报警精确率、每分钟误报数、命中提前量分布，以及窗口级 PR-AUC 和阳性比例基线。展示连续测试轨迹、真实边界和报警，保存每次报警与事件匹配表、参数和可重复运行脚本。小测试集的置信区间应展示，并明确这只是一个 block 内的预实验，不是跨患者或跨会话验证。

结果另存于独立的 `outputs/beta_boundary_pilot/` 时间戳目录。新增脚本与测试，不改写用户 Notebook、PPT 或既有分析结果。测试验证未来输入修改不影响历史特征、拆分无跨界泄漏、报警匹配唯一性和提前量方向。输出成功与否都交付，不能把离线可分性等同于已证实的实时预测。
