# Four-Band Joint Clustering Plan

**Approved design:** A new single-patient/block notebook under `3-bands/` combines Theta 4-8, Beta1 13-24, Beta2 24-40 and high-gamma 70-150 Hz features into one electrode clustering. Two manual K values, additive PCA-distance/cluster/channel review, independent round-two refit, paired audio plots, and both existing baseline modes. Existing beta/global notebooks remain unchanged. No GitHub push.

**Architecture:** A uniquely named `fourband` package reuses root epoch extraction with each actual passband, genericizes feature names, selects redundant predictors within each band, and normalizes feature weights to equal per-band budgets. PCA is descriptive/review only; KMeans uses selected weighted features. Global PCA distance uses the coordinate-wise median of eligible first-round PCs, additionally reporting within-cluster distances so singleton outliers cannot hide at their own centroid. Thresholds are manual, never guessed.
