# 保留幅度的曲线相似度分类

用户确认：形状相同而响应幅度不同的样本不应接近；其余曲线数据比较、音频关系和示例图建议接受。

设计：beta 各段使用相同的 pre-onset 均值减法去除整体偏移，不做逐通道标准差、范数或幅度归一化。使用全体合格样本共有的一个 beta RMS 尺度与固定分段权重，保留幅度比；音频关系使用曲线斜率相关及受限互相关滞后。K-means 直接使用带权欧氏曲线距离，不用忽略幅度的相关距离/DTW或图片像素。

- [x] 测试：偏移不改变曲线特征、幅度翻倍仍翻倍、绝对能量不进入模型、相同形状不同幅度可分开。
- [x] full_curves.py：固定真实 pre/post 及语音进程网格，配对 trial，均值/SEM，完整示例图和单样本图。
- [x] curve_similarity.py：响应向量、音频关系、共享尺度、带权欧氏 K-means/PCA；二轮重新拟合共享尺度和填充。
- [x] pipeline/review：缓存完整曲线，保留旧诊断数据，第一轮/第二轮复用曲线特征；自动筛除/弹窗保持。
- [x] Notebook 参数和说明、用户选择保留、测试和图形检查。

默认 context 0.75 秒；显式设置的更短 pre/post 窗口优先。显示毫秒轴的 speech 时长使用各 block 有效 trial 时长汇总中位数，仅表示归一化显示轴。分类不包含原能量/功率水平特征；原 beta Z 曲线用于展示。单通道图只在第一轮输出以免重复存储。
