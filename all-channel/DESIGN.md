# 全通道曲线形状聚类

输入 DATA_ROOT 与手动 INCLUDED_BLOCKS。每条样本为病人 × block × 通道，汇总同一 block 的配对有效 trial。分类输入直接从连续 beta Hilbert 功率取样的完整数值曲线与音频关系，不使用 PNG 像素、绝对功率或旧能量指标。

用户最新修改：不保留响应幅度差异。每通道减去 pre 均值，再除以整条 pre/speech/post 的逐通道 RMS。三段共用这个尺度，保留方向和相对形状；平坦曲线保持零。归一化后共享训练尺度仅用于配权，不恢复幅度。加权欧氏 K-means；pre/speech/post 预算 0.2/0.6/0.2，音频斜率零延迟相关、带符号峰值互相关和对应延迟的总预算 0.25。保留相邻相关时间点，仅筛常量和过多缺失列。

默认前后各 0.75 秒、各 51 点；speech 101 点。全曲线按物理 0.10 秒平滑。连续功率和音频先各自整段平滑，再每个 trial 一次取样；不拼接分别处理的窗口。图和分类均为去水平、去幅度后的无量纲 beta 变化，不显示基线 Z，橙色音频用 block speech 峰值归一化。语音时间归一化后映射到全部 trial 的中位时长用于毫秒显示，前后保留真实秒数。每个通道保存均值与 trial SEM；两轮各簇保存均值与样本 SEM、双轴完整曲线和构成统计。

两轮 K 手动设置。PCA 用于显示与复审，分类使用全部保留的带权曲线特征。第一轮后自动筛除一次成员占比 ≤5% 且前三 PC 样本方差之和 > 非小簇中位数 3 倍的簇，阈值可调。无参照或单成员不自动删除；报告先保存，再弹出原 Tk 3D 复审窗口。保留原坐标和编号，自动排除不可恢复。Apply 后才可第二轮；整簇、sample_id、可选距离排除取并集并分别审计。

第二轮复用缓存，独立重拟合共享尺度、K-means 与 PCA，保留第一轮输出及质量排除。输入路径和基线沿用根流程，默认 file，可明确选择 pre_onset；文件缺失或任一 block 失败即停止，不静默跳过。用户已有病人/block/K 参数和根项目修改保留。

仅执行此粒度的全局两轮聚类，不执行跨 block 汇总、single-trial、留一病人、分半或 bootstrap，不作稳定性和生理类型结论。详细参数、输出与限制见 README.md。
